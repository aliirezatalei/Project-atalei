# Weekly Task & Habit Tracker

A Python program that helps you keep track of your tasks and habits for the week.

## How it works

- **Tasks** are things you do once, on one day (like "Pay Bills" on Monday).
- **Habits** are things you want to do every day (like "Drink Water").
- Everything is saved while the program runs, but it resets when you restart it.

## How to use it

1. Open `Project-atalei.ipynb` in Jupyter or VS Code.
2. Run all the cells in order. The last cell shows the menu.
3. Type a number from 1 to 5 and press Enter:
   - 1: Add a task or habit
   - 2: Mark a task or habit as complete
   - 3: Remove a task or habit
   - 4: View a weekly or daily report
   - 5: Exit
4. Answer the follow-up questions. Type `t` for task or `h` for habit, or `w` for weekly report or `d` for daily report.

Days need to be spelled out, like `Monday`.
